# Vexidus Tokens
Official repository for Vexidus blockchain native tokens

## Getting Started
This repository is only for tokens that are native for the Vexidus blockchain.

## What to Submit
See the sample.json file in the token list for the correct format. 

Add your information, ensure it is correct, and then upload.

Your icon must be hosted via IPFS and link included.

Acceptable socials include website, X (Twitter), Telegram, Discord.

Include your creator wallet in the request form.

Request pull.

## Using VexForge
If you create your token with VexForge, you should use an IPFS (Arweave, Pinata, etc).

## Issues
If your format is incorect our blockchain will not pickup your metadata.

Do not submit images only.

If your token is marked immutable, not changes can be made.

We do not maintain metadata of non-native tokens except EVM tokens. EVM tokens should submit manual requests above. Please note that this only is for tokens without existing metadata on their native chain. If your already have metadata connected, we can not override it.
